# AGENTS.md - Docs

Docs are part of the product architecture. Keep them current when code or product direction changes.

## Required Docs

- `ARCHITECTURE.md`: dependency direction and system shape
- `AI_ORCHESTRATION.md`: live AI strategy, council roles, schemas, failures
- `PROSE_QUALITY.md`: rubric for good writing output
- `TRACKING.md`: open issues, review comments, risks, follow-up decisions
- `CHANGELOG.md`: chronological changes
- `LESSONS_LEARNED.md`: principles learned from mistakes and review
- `RESEARCH.md`: contest evidence and interpretation
- `SELF_REVIEW.md`: periodic self-review checkpoints

## Update Rules

- Add changelog entries for user-visible, architecture, AI, contract, or test changes.
- Add lessons when a mistake changes how agents should work.
- Keep tracking items actionable and owned by status.
- Do not bury current blockers in prose-only summaries.
